Cadastro de usuários

Painel do administrador. Roda no seu PC, não precisa de internet e não deve ser aberto pelos operadores.

Passo 1

Destrancar o cofre

Passo 2

Usuários

Adicionar / trocar senha

Se o login já existir, a senha dele é substituída.

Passo 3 (opcional)

Banco na nuvem

Só mexa aqui se trocar de projeto no Supabase.

Passo final

Gerar o arquivo

Salve por cima de js/usuarios.js e depois publique no GitHub. Enquanto você não publicar, nada mudou para os operadores.
